# Kaiserlich web

## Requisitos

- Node.js 20.19 o posterior.
- VS Code es opcional; cualquier editor de texto sirve.

## Iniciar en tu computadora

Desde esta carpeta, abre una terminal:

```sh
npm install
npm run dev
```

Abre la dirección local que muestra Vite. Para comprobar tipos y generar una versión de producción:

```sh
npm run typecheck
npm run build
```
